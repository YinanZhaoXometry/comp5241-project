Foundations

The token sheet and component kit for the visual refresh. One warm parchment canvas, one terracotta accent, serif for titles and sans for interface — every screen in the inventory is composed from these parts.

Color

Warm neutrals only — every gray carries a yellow-brown undertone. Terracotta is the single accent, reserved for primary actions and live moments. Focus blue appears nowhere except the keyboard focus ring.

Typography

Georgia carries every headline at weight 500 — book-title gravity with zero webfont dependency, so the CSP font-src 'self' rule holds. System sans handles UI text; mono handles code and numerics.

Shape & depth

Radii move up from the current 4–6px to an 8/12/16 scale — the cozy-modern shift. Depth is ring-based: a 1px warm halo instead of drop shadows, with one whisper-soft shadow allowed for overlays and floating elements only.

Buttons

One primary action per view. Secondary is Warm Sand, quiet is a hairline outline, danger is never filled until confirmation. Minimum height 44px everywhere.

Forms & answer rows

Input borders use Stone Gray to hold the 3:1 non-text contrast requirement; the focus ring is Focus Blue with a 3px halo. Practice answer rows are 64px tall with a clear selected state.
